# Treningownik

Prywatny, lokalny notatnik treningowy na Androida.

## Funkcje
- atlas ćwiczeń pogrupowany według atlas.kulturystyka.pl
- własne ćwiczenia i własne grupy mięśniowe
- tworzenie i edycja planów treningowych
- dowolna liczba serii; osobne: powtórzenia, ciężar i przerwa dla każdej serii
- tryb treningu z dużym przyciskiem zakończenia serii
- automatyczny timer przerwy i sygnał dźwiękowy
- oznaczenie ↑ / ↓ / = jako zalecenie progresji
- historia treningów
- wszystko działa lokalnie, bez konta i serwera

## Uruchomienie
1. Otwórz folder `Treningownik` w Android Studio.
2. Poczekaj na synchronizację Gradle.
3. Podłącz telefon z włączonym debugowaniem USB lub uruchom emulator.
4. Kliknij Run.

Projekt używa Jetpack Compose. Minimalny Android: 8.0 (API 26).

## Uwaga o Atlasie
Do aplikacji wprowadzono nazwy i podział ćwiczeń. Nie kopiowano zdjęć ani pełnych opisów techniki z serwisu.
